# Kouzina Area Analysis

A web tool for the Kouzina BD team to analyse areas on a map. It is a finished static site: `index.html` contains all the code, data and libraries.

**Open it here: https://shantanu1930.github.io/kouzina-area-analysis/**

Always open it from that link, not as a downloaded file. The free OpenStreetMap map servers it uses only answer pages opened from a web address, so a copy opened from your computer will not load maps or search.

## Updating the tool

Upload the new build's files (`index.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`) over the old ones in this repository (**Add file → Upload files** on `main`). The site updates on its own within a few minutes. There is no build step.
